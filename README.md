## Getting Started

1. Clone the repository
```bash
git clone https://github.com/abdelhalimyasser/machine-learning-models-2026-fcai-cu.git
cd machine-learning-models-2026-fcai-cu
```
2. Do your work then
```bash
git add .
git commit -m "add your message's" -m "Co-authored-by: `git config user.name` <`git config user.email`>"
```

3. Push your changes
```bash
git push origin main
```

4. Pull the latest changes for the other members  *do this before starting your work*
```bash
git pull origin main
```
